# AI 使用指南

提问时加入下面的关键词或操作，可以提高 AI 调用对应能力的概率。

| 目的 | 推荐关键词或操作 | 示例 |
| --- | --- | --- |
| 普通问答 | 直接提问 | `什么是语义分块？` |
| 搜索本地知识库 | `知识库`、`本地文档`、`笔记库`、`检索`、`调研` | `检索本地知识库，查找自动保存的相关约定。` |
| 指定文件 | 添加文件标签 | `根据我添加的文件，总结核心内容。` |
| 处理选区 | 添加选区标签 | `总结这个选区。` |
| 读取选区上下文 | 添加选区标签；使用 `结合上下文`、`前后文`、`为什么`、`对比` | `结合前后文解释这段结论。` |
| 修改文档或选区 | 添加单个文件或选区标签；使用 `修改`、`改写`、`润色`、`重写`、`替换` | `把这个选区改写得更简洁。` |
| 查询长期记忆 | `查询我的记忆`、`你还记得我`、`我的偏好` | `查询我的长期记忆，我偏好的回答格式是什么？` |
| 保存长期记忆 | `请记住`、`保存到长期记忆`、`以后记得` | `请记住：我偏好先给结论。` |
| 沿用个人风格 | `按我之前的风格`、`照旧`、`像平时一样` | `按我之前的风格润色这个选区。` |
| 联网搜索 | `联网搜索`、`网上搜索`、`最新`、`实时`、`新闻` | `联网搜索 React 的最新稳定版本。` |
| 对照本地与网络资料 | 同时使用 `本地知识库` 和 `联网`、`官网`、`最新资料` | `对照本地知识库和最新官网资料，判断这条配置是否过时。` |
| 查询当前时间 | `当前时间`、`今天日期`、`星期几` | `今天是几号，星期几？` |
